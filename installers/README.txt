Vlera Dent - Windows Installer

Si instalohet:
1. Hape file-in Install-VleraDent.cmd me double-click.
2. Nese Windows pyet per leje, kliko Run / More info / Run anyway.
3. Pasi te kryhet, Vlera Dent del si ikone ne Desktop dhe Start Menu.

Shenim:
- Aplikacioni punon online dhe hap sistemin ne Render/Supabase.
- Duhet internet.
- Duhet Microsoft Edge ose Google Chrome.
- Per telefon, hape linkun ne Chrome/Safari dhe perdor Add to Home Screen.
- Linku online: https://hospitalmanagamentsystem.onrender.com/Auth/Login
